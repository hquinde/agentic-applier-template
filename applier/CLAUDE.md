# applier/

# Purpose

- Where batches of NYC job applications get reviewed, filled out, and submitted. [CONTEXT.md](CONTEXT.md) is the full workflow and fit-review rulebook — read it before running a batch.

# Source Files (you add these — not included in this template)

- `resume-context.md` — full-detail record of your background: education, work experience, projects, and leadership/campus involvement. Never sent to employers as-is — source for any resume-adjacent factual claim in an application.
- `questions-context.md` — raw source material for application essay/short-answer questions (references, motivation themes, background talking points, availability/logistics) plus a fixed Work Authorization & Location facts block, reused verbatim across every application.
- `workday-fields.md` — canonical field values (work experience, education, EEO answers) and known UI quirks for Workday-based application forms, so they don't get re-derived or re-discovered on every new Workday application.
- Your resume PDF and (optionally) transcript PDF — used to fill applications and to cross-check GPA/coursework claims.

# Rules

- Don't write into memory.
- Ask if unsure — see [CONTEXT.md](CONTEXT.md)'s "When to ask vs. proceed autonomously" for specifics.
